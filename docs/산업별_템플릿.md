# 산업별 팩트 템플릿

`config/industry-templates.json` 은 업종마다 꼭 봐야 할 지표의 정의, 단위, 비교 기준, 흔한 오독을 모은 점검표입니다.

## 쓰는 방법

공통 10체크는 그대로입니다. 항목, 가중치, 통과 기준을 바꾸지 않습니다. SKILL은 체크 3(수치 성격)과 체크 5(동일 기준·시간축)를 판정할 때 이 파일을 대조하고, 결과를 카드의 `산업 지표 점검` 줄에 적습니다.

**템플릿은 수치의 출처가 아닙니다.** 수치 예시를 일부러 넣지 않았습니다. 실제 값은 공시와 통계 원문에서 가져와야 합니다.

## 담긴 업종

| 키 | 업종과 별칭 | 지표 |
|---|---|---|
| `shipbuilding` | 조선 | 선가, 수주잔고, CGT와 척수 |
| `battery` | 배터리, 이차전지 | 메탈 가격, 가동률, AMPC, 배터리 사용량 |
| `refining` | 정유 | 정제마진, 래깅 효과와 재고 관련 손익, 유가, 가동률 |
| `petrochemical` | 석유화학, 석화 | 에틸렌 스프레드, 납사 가격, 가동률, 원료 투입 시차 |
| `aviation` | 항공, LCC항공 | RPK, ASK, 탑승률 |
| `cable` | 전선 | 구리 가격, 수주잔고 |

업종마다 `macro_controls` 도 있습니다. 환율처럼 함께 통제해야 할 변수이며, 반론 근거 점수의 거시 변수 축에서 그대로 씁니다.

## 정의를 얼마나 확인했나

각 지표의 `verification` 값을 먼저 보세요.

| 값 | 뜻 |
|---|---|
| `primary` | 공식 기관·법령·1차 자료의 본문을 열어 확인했습니다. |
| `secondary` | 보도나 시장조사기관 자료의 본문을 열어 확인했습니다. 공식 정의 문서는 확인하지 못했습니다. |
| `partial` | 출처 위치만 찾았거나 일부만 확인했습니다. 사용 전에 원문을 직접 확인해야 합니다. |

2026-11-05 기준으로 확인하지 못한 곳은 이렇습니다.

- **CGT**: OECD 원문(`C/WP6(2006)7`)은 자동 열람이 막혀 위치만 확인했습니다. 정의는 폴란드 정부의 공식 설명과 보도로 확인했습니다.
- **신조선가 지수**: 클락슨의 공식 방법론 문서를 찾지 못해 보도에 나온 설명만 적었습니다. 지수 기준 시점도 본문으로 확인하지 못해 뺐습니다.
- **LME 가격 단위**: 계약 명세 페이지는 자동 열람이 막혀 검색 결과로만 봤습니다. `partial` 로 표시했습니다.
- **래깅 효과**: 회계 기준 문서가 아니라 보도의 설명입니다. 석유화학 항목은 정유의 개념을 빌린 것이라 회사 설명 확인이 필요합니다.
- **수주잔고의 공시 기준**: 사업보고서에 `매출 및 수주상황` 항목이 있다는 것만 확인했고, 공시 서식의 기재 기준 원문은 보지 못했습니다.
- **AMPC**: 법 조문으로 kWh 기준임을 확인했습니다. 이후 개정 여부와 회사별 회계 처리는 따로 확인해야 합니다.

## 지표 항목 형식

```json
{
  "id": "order_backlog",
  "name": "수주잔고(수주잔량)",
  "required": true,
  "definition": "정의 문장",
  "units": ["CGT", "척"],
  "comparison_basis": ["같은 기준 시점", "같은 단위"],
  "common_misreads": ["흔한 오독"],
  "source_ids": ["sources 의 키"],
  "verification": "secondary"
}
```

업종을 추가할 때는 `aliases` 에 쓰는 이름을 모두 적고, 출처를 실제로 연 뒤 `sources` 에 `opened` 값을 사실대로 적어 주세요. `node --test` 가 필수 항목, 출처 연결, 수치 예시 포함 여부를 검사합니다.
