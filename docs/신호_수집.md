# 신호 수집 도구

`scripts/collect-signals.mjs` 는 DART 공시, 경제지 RSS, 통계 발표 일정을 모아 이상 신호 후보 목록을 만듭니다. Node 20 이상만 있으면 되고 설치할 패키지는 없습니다.

## 먼저 알아 둘 점

- **결과는 확정 사실이 아닙니다.** 모든 항목에 `본문 확인 전 후보`가 붙습니다. 제목과 날짜만 모은 목록이므로, 원문을 열어 확인한 것만 발제 근거로 쓸 수 있습니다.
- **실시간이 아니라 주기 수집입니다.** 돌린 시점의 자료만 모읍니다. 놓치는 공시와 기사가 있을 수 있어 웹 검색을 대신하지 않습니다.
- **기사 본문은 저장하지 않습니다.** 제목, 주소, 날짜, 걸린 이유만 남깁니다. 본문과 요약은 업종어·신호어를 찾는 데만 쓰고 버립니다.

## 실행

```bash
node scripts/collect-signals.mjs
node scripts/collect-signals.mjs --out HB_Output/signals --state HB_Output/signals/state.json
```

결과는 `HB_Output/signals/YYYY_MM_DD_HHmmsignals.json` 으로 저장합니다. 이름이 겹치면 `_2`, `_3`을 붙이고 덮어쓰지 않습니다. `--state` 를 주면 이전 실행에서 본 후보를 기억해 `new_since_last_run` 값을 넣습니다.

소스 하나가 실패하거나 빠져도 나머지는 계속 모읍니다. 어떤 소스를 왜 건너뛰었는지는 화면과 결과의 `sources` 에 적습니다. 종료 코드는 설정 파일이 잘못됐을 때만 `2`입니다.

## DART 키 넣기

키는 환경변수 `DART_API_KEY` 로만 받습니다. 설정 파일에 적으면 도구가 실행을 거부합니다. 키가 없으면 공시를 건너뛰었다고 적고 나머지를 수집합니다.

키 발급은 사용자가 [OpenDART](https://opendart.fss.or.kr/) 에서 직접 합니다.

```bash
# macOS · Linux: 현재 터미널에서만 유효합니다
export DART_API_KEY='발급받은_키'
node scripts/collect-signals.mjs
```

```powershell
# Windows PowerShell: 현재 창에서만 유효합니다
$env:DART_API_KEY = '발급받은_키'
node scripts/collect-signals.mjs
```

키를 저장소, 로그, 스크린샷에 남기지 마세요. 도구도 결과와 오류 메시지에서 키 값을 지운 뒤 기록합니다.

## 무엇을 후보로 잡나

| 소스 | 후보 조건 |
|---|---|
| DART | 공시유형 `B`(주요사항)·`I`(거래소), 유가증권시장(`corp_cls: Y`) 중 보고서명이 `report_keywords` 에 걸린 것. 업종은 회사 이름으로 찾고, 못 찾으면 `업종 미분류`로 남깁니다. |
| RSS | 최근 7일 기사 중 업종어와 신호어(`signal_terms`)가 함께 걸린 것. 날짜가 없으면 `발행시각 미확인`으로 남깁니다. |
| 일정 | 일정표 안내 페이지, 관찰한 반복 일정, 사용자가 적은 일정 중 앞뒤 7일 안의 것. |

이 조건은 단순 문자열 대조입니다. "평소와 다른지"를 도구가 판단하지 않습니다. 그 판단은 SKILL의 STEP 2에서 기준선과 대조해 합니다.

## 설정 고치기

`config/collector.sources.json` 을 고치거나 복사해 `--config` 로 지정합니다.

- **빈 자리 채우기**: `url` 이 빈 항목은 공식 주소를 확인하지 못한 자리입니다. 주소를 넣고 `enabled` 를 `true` 로 바꿔 주세요.
- **일정 추가**: 협회·기관의 발표 일정을 `calendar.events` 에 적습니다. 처음에는 비어 있습니다.

```json
{ "name": "일정 이름", "date": "YYYY-MM-DD", "publisher": "기관", "url": "https://...", "industries": ["조선"] }
```

- **보고서명 추가**: `dart.report_keywords` 에 넣습니다. 띄어쓰기와 가운뎃점은 무시하고 대조합니다. 확인하지 못한 `생산중단`, `영업(잠정)실적` 계열은 기본값에서 뺐으니 필요하면 공시 원문에서 이름을 확인해 추가해 주세요.
- **회사·키워드**: `industries` 의 목록은 시작용 예시입니다. 관심 기업에 맞게 고쳐 주세요.

## 기본 소스와 확인 기록

아래는 2026-11-05에 실제로 응답을 받아 본 주소입니다. 주소와 조건은 바뀔 수 있습니다.

### DART OpenAPI

[공시검색 개발가이드](https://opendart.fss.or.kr/guide/detail.do?apiGrpCd=DS001&apiId=2019001)에서 요청 주소, 인자, 응답 필드, 오류 코드를 확인했습니다. 공시 원문 주소는 같은 가이드의 뷰어 연결 예시를 따랐습니다. **유효한 키로는 시험하지 못했습니다.** 정상 응답은 가이드 형식에 맞춘 가짜 응답으로 시험했고, 실제 서버에는 무효한 키를 보내 오류 코드 `010` 처리와 키 값이 남지 않는 것만 확인했습니다.

### RSS

이용 조건은 RSS 안내 페이지와 피드 안의 문구만 봤습니다. 약관 전문은 사용자가 확인해 주세요. **아래 제한은 법률 판단이 아니라 각 언론사가 적어 둔 문구를 옮긴 것입니다.**

| 피드 | 기본값 | 확인한 조건 |
|---|---|---|
| 한국경제 경제 | 켜짐 | 저작권 문구만 확인 |
| 머니투데이 최신기사 | 켜짐 | 저작권 문구만 확인, 공식 안내 페이지는 못 찾음 |
| 이투데이 전체기사 | 켜짐 | 저작권 문구만 확인, 공식 안내 페이지는 못 찾음 |
| 파이낸셜뉴스 실시간뉴스 | 켜짐 | 저작권 문구만 확인, 공식 안내 페이지는 못 찾음 |
| 연합뉴스 경제·산업 | **꺼짐** | 비상업적 블로그와 개인 용도만 허용, 피드에 "AI 학습 및 활용 금지" 표기 |
| 매일경제 경제·기업/경영 | **꺼짐** | 안내 페이지에 "무단 전재, 재배포 및 AI학습 이용 금지" 표기 |
| 서울경제 기업 | **꺼짐** | 개인의 비상업적 사용만 허용, 다수 대상 상업적 활용과 AI학습 이용 금지 표기 |
| 뉴시스, 뉴스1, 정책브리핑 | 빈 칸 | 공식 피드 주소를 확인하지 못함 |

꺼진 피드는 조건을 읽고 본인 용도에 맞을 때만 직접 켜 주세요. 수집 결과를 AI 도구에 넘기는 쓰임이 이 조건에 맞는지는 사용자가 판단해야 합니다.

### 통계 일정

- [KOSIS 국가통계 공표일정](https://kosis.kr/serviceInfo/statisPublicationList.do): 결과공표 예정을 월 단위로 안내합니다. 날짜를 자동으로 만들지 않고 "일정표 확인" 후보로만 넣습니다.
- 관세청 수출입 현황 잠정치(1·11·21일): [KDI 경제정보센터 목록](https://eiec.kdi.re.kr/policy/materialList.do?pg=&pp=20&topic=O) 등에서 관찰한 날짜이며 **공식 일정표가 아닙니다.** 주말·공휴일이면 밀립니다. 그래서 `basis` 를 `observed_not_official` 로 표시합니다.

## 주기 실행 예시

아래 설정을 직접 등록하기 전까지는 아무것도 자동으로 돌지 않습니다. 키 등록과 예약 실행은 사용자가 정하고 책임지는 일입니다.

### Cron (macOS · Linux)

키를 crontab에 직접 적지 말고, 권한을 좁힌 별도 파일에 두세요. 이 파일은 저장소 밖에 둡니다.

```bash
# ~/.config/hb/dart.env  (chmod 600) 내용
# export DART_API_KEY='발급받은_키'

# crontab -e: 평일 오전 8시 30분에 실행
30 8 * * 1-5 . "$HOME/.config/hb/dart.env" && cd "$HOME/journalist-skill" && node scripts/collect-signals.mjs --state HB_Output/signals/state.json >> HB_Output/signals/collect.log 2>&1
```

### GitHub Actions

**공개 저장소의 Actions 산출물은 저장소를 읽을 수 있는 사람이면 내려받을 수 있습니다.** 수집 결과에 관심 업종이 드러나므로 비공개 저장소에서 돌리기를 권합니다. 결과를 커밋하지 않습니다.

저장소 설정의 Actions secrets에 `DART_API_KEY` 를 등록한 뒤, 아래 내용을 `.github/workflows/collect.yml` 로 직접 추가해 주세요. 이 저장소에는 넣어 두지 않았습니다.

```yaml
name: 신호 수집
on:
  schedule:
    - cron: '30 23 * * 0-4' # UTC 기준, 한국 시간 평일 오전 8시 30분
  workflow_dispatch:
permissions:
  contents: read
jobs:
  collect:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '24'
      - run: node scripts/collect-signals.mjs --out out
        env:
          DART_API_KEY: ${{ secrets.DART_API_KEY }}
      - uses: actions/upload-artifact@v4
        with:
          name: signals
          path: out/
          retention-days: 7
```

GitHub 예약 실행은 정시에 돌지 않고 늦어질 수 있습니다.
